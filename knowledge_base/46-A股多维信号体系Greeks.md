# A股多维信号体系 v1.0

> 借鉴AlphaGBM期权Greeks思想，构建A股版多维信号体系
> 最后更新: 2026-04-23

---

## 核心理念

AlphaGBM用Greeks（Delta/Gamma/Vega/Theta）多维度描述期权状态。
同样，一只股票的状态也需要**多个正交指标**共同描述。

**单一指标有局限性：**
- 只看涨幅 → 可能追高被套
- 只看量能 → 可能是对倒
- 只看形态 → 可能逆势而行

**多维信号优势：**
- 各指标相互验证，减少假信号
- 快速定位股票当前状态特征
- 不同市场环境下各指标权重可调

---

## 六大信号详解

### 1. Delta（趋势方向）

**含义**：股票的趋势方向，类比期权Delta表示标的资产涨跌方向

**计算方式**：
```
Delta = f(MA排列, 价格位置, 趋势线)

MA多头排列: MA10 > MA20 > MA60 → Delta > 0
MA空头排列: MA10 < MA20 < MA60 → Delta < 0
价格在MA60上方 → Delta +0.5
价格在MA60下方 → Delta -0.5
```

**取值范围**：-1.0 ~ +1.0
- +1.0：完美上升趋势（均线多头 + 价格强势）
- -1.0：完美下降趋势（均线空头 + 价格弱势）
- 0.0：震荡无方向

**信号阈值**：
| Delta | 含义 | 操作 |
|-------|------|------|
| > 0.7 | 强势上升 | 积极参与 |
| 0.3~0.7 | 偏强 | 择时做多 |
| -0.3~0.3 | 无方向 | 观望 |
| -0.7~-0.3 | 偏弱 | 回避 |
| < -0.7 | 弱势下降 | 清仓回避 |

---

### 2. Gamma（动量加速度）

**含义**：趋势的加速度，类似期权Gamma表示Delta变化的速率。加速上涨的股票更有惯性。

**计算方式**：
```
Gamma = f(近期涨幅变化, 成交量变化, 动能指标)

近5日涨幅 > 前5日涨幅 → Gamma正（加速）
成交量逐日放大 → Gamma正（量能配合）
MACD柱放大 → Gamma正
```

**取值范围**：-1.0 ~ +1.0
- +1.0：动量加速（越涨越快）
- -1.0：动量衰减（涨势衰竭）
- 0.0：动量平稳

**信号阈值**：
| Gamma | 含义 | 操作 |
|-------|------|------|
| > 0.5 | 加速上涨 | 顺势追入 |
| 0.2~0.5 | 温和上涨 | 持股待涨 |
| -0.2~0.2 | 动能平稳 | 观察 |
| -0.5~-0.2 | 动能衰减 | 谨慎 |
| < -0.5 | 趋势衰竭 | 止盈/离场 |

**实战要点**：
- Delta高 + Gamma正 = 主升浪（最强信号）
- Delta高 + Gamma负 = 可能是顶部（背离）
- Gamma从负转正 = 动量拐点，可关注

---

### 3. Vega（资金情绪）

**含义**：市场情绪敏感度，类似期权Vega表示波动率变化对价格的影响。Vega高表示资金关注度高。

**计算方式**：
```
Vega = f(主力净流入, 大单净流入, 换手率变化, 融资融券)

主力净流入 > 0 → Vega正
大单买入占比 > 20% → Vega正
换手率逐日放大 → Vega正
融资余额上升 → Vega正
```

**取值范围**：-1.0 ~ +1.0
- +1.0：资金强力买入
- -1.0：资金出逃
- 0.0：资金中性

**信号阈值**：
| Vega | 含义 | 操作 |
|------|------|------|
| > 0.6 | 资金追捧 | 积极参与 |
| 0.3~0.6 | 资金流入 | 持股 |
| -0.3~0.3 | 资金平衡 | 观望 |
| -0.6~-0.3 | 资金流出 | 减仓 |
| < -0.6 | 资金出逃 | 清仓 |

**实战要点**：
- Delta + Gamma + Vega 三者同正 = 极强信号
- Vega突然放大但价格不涨 = 警惕（可能是对倒）
- Vega持续为负 = 资金持续不认可

---

### 4. Theta（量能健康度）

**含义**：时间价值损耗，类似期权Theta表示时间流逝对价格的影响。量能健康度表示量价配合是否健康。

**计算方式**：
```
Theta = f(放量突破, 回调缩量, 量价背离)

放量上涨 + 缩量回调 → Theta正
放量下跌 + 缩量反弹 → Theta负
量价背离 → Theta负
```

**取值范围**：-1.0 ~ +1.0
- +1.0：量价完美配合（涨时放量、跌时缩量）
- -1.0：量价背离（涨时缩量、跌时放量）
- 0.0：量价一般

**信号阈值**：
| Theta | 含义 | 操作 |
|-------|------|------|
| > 0.5 | 量价健康 | 趋势可持续 |
| 0.2~0.5 | 量价正常 | 正常操作 |
| -0.2~0.2 | 量价一般 | 谨慎 |
| -0.5~-0.2 | 量价背离 | 警惕 |
| < -0.5 | 严重背离 | 回避 |

**实战要点**：
- 主升股票典型特征：Delta高 + Gamma正 + Theta正
- 放量滞涨：Theta负，可能是顶部
- 缩量下跌：Theta负，可能是洗盘（需结合位置判断）

---

### 5. Alpha（相对强弱）

**含义**：个股相对于板块和指数的超额收益能力。

**计算方式**：
```
Alpha = f(个股涨幅 vs 板块涨幅, 个股涨幅 vs 指数涨幅)

个股涨幅 > 板块涨幅 2%以上 → Alpha正
个股涨幅 > 指数涨幅 1%以上 → Alpha正
创板块新高 → Alpha正
```

**取值范围**：-1.0 ~ +1.0
- +1.0：板块龙头/龙头股
- -1.0：板块落后股
- 0.0：与板块同步

**信号阈值**：
| Alpha | 含义 | 操作 |
|-------|------|------|
| > 0.7 | 板块龙头 | 重仓持有 |
| 0.3~0.7 | 相对强势 | 积极参与 |
| -0.3~0.3 | 与板块同步 | 随板块操作 |
| -0.7~-0.3 | 相对弱势 | 回避 |
| < -0.7 | 板块拖累 | 清仓 |

**实战要点**：
- Alpha是选股的核心：宁愿选Alpha高的弱趋势股，也不选Alpha低的强趋势股
- 主升系统要求Alpha > 0.3
- Beta（波动率）高的股票Alpha往往也高（高风险高收益）

---

### 6. Sigma（波动风险）

**含义**：波动率/风险，类似期权Sigma表示波动率大小。高Sigma意味着高风险高收益。

**计算方式**：
```
Sigma = f(历史波动率, 与指数相关性, 风险信号)

HV（20日历史波动率）> 30% → Sigma高
与指数Beta > 1.5 → Sigma高
出现风险信号 → Sigma极高
```

**风险信号（Sigma触发）**：
- 高位放量滞涨（连续3日创新高但涨幅<1%）
- 巨量阴线（成交量>2倍平均且跌幅>5%）
- 断头铡刀（跌破重要均线8%以上）
- 连续加速上涨后高位长阴

**取值范围**：0 ~ +2.0（只衡量风险大小，越高越危险）
- 0~0.3：低波动/稳健
- 0.3~0.6：正常波动
- 0.6~1.0：高波动/高风险
- > 1.0：极高风险/规避

**信号阈值**：
| Sigma | 含义 | 操作 |
|-------|------|------|
| < 0.3 | 低风险 | 正常操作 |
| 0.3~0.6 | 正常风险 | 控制仓位 |
| 0.6~1.0 | 高风险 | 轻仓/止损严 |
| > 1.0 | 极高风险 | 清仓回避 |

## 综合信号：六维信号矩阵

每只股票都可以用六维信号描述：

```
股票代码 | Delta | Gamma | Vega | Theta | Alpha | Sigma | 综合评分
--------|-------|-------|------|-------|-------|-------|----------
000001  | +0.8  | +0.6  | +0.5 | +0.4  | +0.7  |  0.3  |  85分
000002  | +0.3  | -0.2  | -0.1 | +0.1  | -0.2  |  0.5  |  45分
```

**综合评分计算**：
```
综合评分 = Delta×20 + Gamma×15 + Vega×15 + Theta×10 + Alpha×25 + (1-Sigma)×15

满分100分，各指标权重可根据市场环境调整
```

**评分等级**：
| 评分 | 等级 | 信号 |
|------|------|------|
| 80+ | S级 | 完美共振，强烈做多 |
| 70~80 | A级 | 多指标共振，积极参与 |
| 60~70 | B级 | 部分指标好，可操作 |
| 50~60 | C级 | 需等待更好的信号 |
| < 50 | D级 | 风险区，回避 |

## 实战应用

### 选股标准（主升系统）

**S/A级股（评分70+）**：
```
Delta > 0.3  AND
Gamma > 0.2  AND
Vega  > 0.3  AND
Alpha > 0.3  AND
Sigma < 0.6  AND
```

**选股优先级**：
1. S级优先（完美共振）
2. A级次之（多指标共振）
3. B级观察（部分指标好）

### 持仓管理

**根据信号变化调整仓位**：

| 信号变化 | 操作 |
|----------|------|
| Delta持续上升 | 加仓 |
| Gamma由正转负 | 减仓 |
| Vega突然放大 | 警惕（可能是顶部） |
| Sigma上升 | 止损收紧 |
| Alpha持续上升 | 持有 |
| 综合评分跌破60 | 清仓 |

### 风险控制

**一票否决（Sigma极高）**：
- Sigma > 1.0，无论其他指标多好，一律回避
- 出现风险信号（高位放量滞涨/巨量阴），立即退出

**止损规则**：
- Sigma突然放大 → 止损
- Delta跌破0 → 止损
- 综合评分跌破50 → 止损

## 与双系统模型整合

### 六层过滤 → 六维信号

| 双系统层 | 对应信号 | 过滤条件 |
|----------|----------|----------|
| 第一层：指数强趋势 | Delta(指数) | 上证Delta > 0 |
| 第二层：主线板块 | Alpha(板块) | 板块Alpha > 0.3 |
| 第三层：龙头优先 | Alpha(个股) | 个股Alpha > 0.5 |
| 第四层：量价强一致 | Theta | Theta > 0.3 |
| 第五层：分歧确认 | Gamma | Gamma由负转正 |
| 第六层：失败压制 | Sigma | Sigma < 0.6 |
